# dokodemo

> 一个 Win10 磁贴风格的桌面快捷方式启动器 —— 干净、轻量、随手即开。

`dokodemo` 是一款基于 PyQt5 的桌面快捷方式管理器，扫描指定文件夹中的 `.lnk` 快捷方式，以磁贴式布局呈现，支持分组管理、拖拽排序、窗口停靠，单击即启动并自动最小化。

---

## ✨ 功能特性

### 核心功能

- **📂 自动扫描** — 扫描指定目录下的 `.lnk` 快捷方式，自动提取目标程序图标
- **🧱 磁贴式布局** — 顶部平铺全部快捷方式，下方分组可独立调整宽度，流式排列
- **🗂️ 分组管理** — 自由创建分组，拖拽排序分组和快捷方式，支持跨分组拖拽
- **🎨 8 种预设配色** — 每个分组可独立设置配色，视觉上一目了然
- **🖱️ 单击启动** — 单击快捷方式立即启动，窗口自动最小化
- **📌 六种停靠模式** — 自由 / 全屏 / 居中 / 靠左 / 靠右 / 左下，一键切换

### 体验优化

- **🪟 无边框圆角** — 自定义标题栏，Win10 浅色一体感风格
- **↔️ 边缘缩放** — 拖拽窗口四边/四角自由调整大小
- **✋ 拖拽归类** — 图标拖到空白区域即可移出分组
- **⚡ 单实例运行** — 重复启动自动唤醒已有实例

## 🚀 快速开始

### 环境要求

- Windows 系统
- Python 3.8+

### 安装

```bash
pip install -r requirements.txt
```

### 运行

```bash
python main.py
```

### 打包为 exe

```bash
pyinstaller --noconsole --icon=app.ico --name=dokodemo --additional-hooks-dir=hooks main.py
```

## 📖 使用说明

1. **设置目录** — 点击右上角 ⚙ 设置 →「设置目录」，选择存放 `.lnk` 快捷方式的文件夹
2. **刷新加载** — 点击标题栏 ↻ 刷新按钮扫描目录，新快捷方式出现在顶部"全部"区域
3. **创建分组** — 设置 →「添加分组」，输入分组名称
4. **拖拽分类** — 拖动快捷方式到分组内；拖到空白区域则移出分组回到顶部
5. **分组操作** — 拖拽分组标题栏调整顺序；右键标题可重命名、换配色、删除分组
6. **调整宽度** — 拖拽分组右边缘调整分组宽度
7. **停靠方式** — 设置 →「停靠方式」，可选自由/全屏/居中/靠左/靠右/左下
8. **调整窗口** — 拖拽窗口边缘调整大小；手动调整后停靠模式自动切回「自由」
9. **最小化** — 点击快捷方式或空白区域，窗口自动最小化
10. **退出** — 点击标题栏 ✕ 按钮直接退出程序

## 🏗️ 项目结构

```
dokodemo/
├── main.py                  # 程序入口（单实例检测、主窗口启动）
├── app.ico                  # 应用图标
├── requirements.txt         # 依赖列表
├── hooks/                   # PyInstaller 打包钩子
├── config.json              # 配置文件（运行后生成）
└── src/
    ├── main_window.py       # 主窗口（标题栏、停靠模式、原生消息处理）
    ├── app_icon.py          # 应用图标生成
    ├── config.py            # 配置管理（分组、停靠模式、窗口几何持久化）
    ├── shortcut.py          # 快捷方式扫描与图标提取
    ├── shortcut_item.py     # 单个快捷方式组件（单击启动、拖拽、右键菜单）
    ├── group_widget.py      # 分组组件（标题、宽度拖拽、流式内容）
    ├── groups_container.py  # 分组容器（顶部全部 + 下方分组流布局）
    ├── flow_layout.py       # 流式布局（支持 heightForWidth）
    └── styles.py            # 全局 QSS 样式
```
