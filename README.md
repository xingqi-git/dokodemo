# dokodemo

> 一个轻量、优雅的桌面快捷方式管理工具 —— 把杂乱的快捷方式整理得井井有条。

`dokodemo`是一款基于 PyQt5 的桌面快捷方式管理器，扫描指定文件夹中的 `.lnk` 快捷方式，支持分组管理、拖拽排序、自定义布局。单击即启动，关闭驻留托盘，让你随时随地快速启动常用程序。

---

## ✨ 功能特性

### 核心功能

- **📂 自动扫描** — 扫描指定目录下的 `.lnk` 快捷方式，自动提取目标程序图标（去除快捷方式箭头）
- **🗂️ 分组管理** — 自由创建分组，拖拽排序快捷方式和分组，支持跨分组拖拽
- **🎨 8 种预设配色** — 每个分组可独立设置配色，视觉上一目了然
- **🔍 图标大小可调** — 32px ~ 128px 无级调节，随调随见
- **📐 列数自由配置** — 1~5 列布局，适应不同屏幕和使用习惯
- **🖱️ 单击启动** — 单击快捷方式立即启动，自动隐藏到托盘

### 体验优化

- **🪟 无边框设计** — 自定义标题栏，干净清爽
- **📥 托盘驻留** — 关闭窗口不退出，驻留在系统托盘，单击图标秒唤醒
- **⚡ 单实例运行** — 重复启动自动唤醒已有实例，不会开多个窗口

## 🚀 快速开始

### 环境要求

- Windows 系统
- Python 3.8+

### 安装

```bash
pip install -r requirements.txt
```

### 运行

```bash
python main.py
```

### 打包为 exe

```bash
pyinstaller --noconsole --icon=app.ico --name=dokodemo --additional-hooks-dir=hooks main.py
```

## 📖 使用说明

1. **选择目录** — 点击工具栏「选择目录」，选择存放 `.lnk` 快捷方式的文件夹
2. **刷新加载** — 点击「刷新」扫描目录，新快捷方式会进入「未分组」
3. **创建分组** — 点击「添加分组」创建自定义分组
4. **拖拽分类** — 拖动快捷方式到不同分组中进行分类，组内也可拖拽排序
5. **管理分组** — 拖动分组标题栏调整顺序；右键分组标题可重命名、更换配色、删除分组
6. **调整显示** — 拖动「图标大小」滑块调整图标尺寸；拖动「列数」滑块调整布局列数
7. **托盘驻留** — 关闭窗口后程序驻留托盘，单击托盘图标显示/隐藏窗口

## 🏗️ 项目结构

```
dokodemo/
├── main.py                  # 程序入口（单实例、托盘、主窗口启动）
├── app.ico                  # 应用图标
├── requirements.txt         # 依赖列表
├── hooks/                   # PyInstaller 打包钩子
├── config.json              # 配置文件（运行后生成）
└── src/
    ├── main_window.py       # 主窗口（标题栏、工具栏、布局）
    ├── app_icon.py          # 应用图标生成
    ├── config.py            # 配置管理（分组、快捷方式持久化）
    ├── shortcut.py          # 快捷方式扫描与图标提取
    ├── shortcut_item.py     # 单个快捷方式组件（单击启动、拖拽）
    ├── group_widget.py      # 分组组件（标题、快捷方式列表）
    ├── groups_container.py  # 分组容器（网格布局、列数管理）
    ├── flow_layout.py       # 流式布局
    └── styles.py            # 全局样式
```
